# James "Rusty" Haner
Senior Research Software Developer at the Institute for Intelligent Systems, University of Memphis. MS student in General Psychology (expected 2027).

I build research software for education, language, and learning science: adaptive practice systems, linguistic analysis tools, and full-stack web apps in TypeScript, Python, JavaScript, and C#.

## Work at the Institute for Intelligent Systems

### Recent work
Public memphis-iis repositories with commits under my GitHub username, JRustyHaner, in 2025 and 2026:

- [farmer-health](https://github.com/memphis-iis/farmer-health): IIS Django and Python project.
- [CIS-IIS-backend](https://github.com/memphis-iis/CIS-IIS-backend): NestJS backend fork of the Child Impact Statements / Shelby County Kids Data capstone ([shelbycountykiddata.com](https://shelbycountykiddata.com)).
- [lac_sotu_big5_react](https://github.com/memphis-iis/lac_sotu_big5_react): React version of the State of the Union Big 5 dashboard.
- [mofacts-legacy](https://github.com/memphis-iis/mofacts-legacy): The MoFaCTS production system I developed, a web-based adaptive learning platform (Meteor production app and a Svelte rewrite).
- [language_across_cultures_tools](https://github.com/memphis-iis/language_across_cultures_tools): Scripts for the Language Across Cultures project (language processing, data extraction, and video manipulation).
- [mofacts-validator](https://github.com/memphis-iis/mofacts-validator): Python validator for MoFaCTS zip packages (structure, JSON, keys, and cross-references). Personal copy: [JRustyHaner/mofacts-validator](https://github.com/JRustyHaner/mofacts-validator).
- [CIS-IIS](https://github.com/memphis-iis/CIS-IIS): NestJS backend fork of the same capstone (Docker and CI/CD work).
- [CIS-FRONTEND](https://github.com/memphis-iis/CIS-FRONTEND) and [SCKidsData](https://github.com/memphis-iis/SCKidsData): Angular frontend forks of the same capstone.
- [lac_unga_dashboard_react](https://github.com/memphis-iis/lac_unga_dashboard_react): React dashboard for UN General Assembly (UNGA) speech data.
- [glyphwitch](https://github.com/memphis-iis/glyphwitch): Language Across Cultures tools for comparing glyphs and phonemes in documents.

## Featured personal work
- [ThesisServer](https://github.com/JRustyHaner/ThesisServer): Markov chain prediction system from my 2019 MLA thesis, "Pre-LLM Markov Table AI Prediction System," which received the University of Memphis Dan Lattimore Award for Most Innovative Thesis.
- **Psynaptix** (private, plugin tree public at [psynaptix-plugins](https://github.com/JRustyHaner/psynaptix-plugins)): A standalone multisignal measurement service that records and synchronizes real-time learner signals, including EEG from Muse headsets, mouse tracking, behavioral events and external data sources, into timestamp-aligned research exports, built for IRB and HIPAA-ready work.
