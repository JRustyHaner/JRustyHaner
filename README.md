# James "Rusty" Haner
Senior Research Software Developer at the Institute for Intelligent Systems, University of Memphis. MS student in General Psychology (expected 2027).

I build research software for education, language, and learning science: adaptive practice systems, linguistic analysis tools, and full-stack web apps in TypeScript, Python, JavaScript, and C#.

## Work at the Institute for Intelligent Systems
Public memphis-iis repositories with commits under my GitHub username, JRustyHaner:

- [mofacts-legacy](https://github.com/memphis-iis/mofacts-legacy): The MoFaCTS production system I developed, a web-based adaptive learning platform (Meteor production app and a Svelte rewrite).
- [mofacts-validator](https://github.com/memphis-iis/mofacts-validator): Python validator for MoFaCTS zip packages (structure, JSON, keys, and cross-references). Personal copy: [JRustyHaner/mofacts-validator](https://github.com/JRustyHaner/mofacts-validator).
- [mofacts-docker](https://github.com/memphis-iis/mofacts-docker): Docker Compose deployment of MoFaCTS (mini and full stacks).
- [cohmetrix-issues](https://github.com/memphis-iis/cohmetrix-issues): Public issues and distribution repository for Coh-Metrix Core Desktop, a linguistic analysis tool for cohesion and readability.
- [glyphwitch](https://github.com/memphis-iis/glyphwitch): Language Across Cultures tools for comparing glyphs and phonemes in documents.
- [language_across_cultures_tools](https://github.com/memphis-iis/language_across_cultures_tools): Python scripts for Leah Windsor's Language Across Cultures lab.
- [lac_unga_dashboard_react](https://github.com/memphis-iis/lac_unga_dashboard_react): React dashboard for UN General Assembly (UNGA) speech data.
- [lac_sotu_big5_react](https://github.com/memphis-iis/lac_sotu_big5_react): React version of the State of the Union Big 5 dashboard.
- [LAC_Bias-in-Face-and-Emotion-Recognition](https://github.com/memphis-iis/LAC_Bias-in-Face-and-Emotion-Recognition): Code reference for the paper "Bias in Face and Emotion Recognition: Methodological Considerations for Multicultural and Multimodal Research."
- [IISae](https://github.com/memphis-iis/IISae): Institute for Intelligent Systems Assessment Engine (Meteor, with Vagrant and Android/iOS testing).
- [oji-cordova](https://github.com/memphis-iis/oji-cordova): Oji, a Meteor app with Vagrant setup for browser and Cordova/Android testing.
- [CIS-FRONTEND](https://github.com/memphis-iis/CIS-FRONTEND) and [SCKidsData](https://github.com/memphis-iis/SCKidsData): Angular frontend forks of the Child Impact Statements / Shelby County Kids Data capstone ([shelbycountykiddata.com](https://shelbycountykiddata.com)).
- [CIS-IIS](https://github.com/memphis-iis/CIS-IIS) and [CIS-IIS-backend](https://github.com/memphis-iis/CIS-IIS-backend): NestJS backend forks of the same capstone.
- [farmer-health](https://github.com/memphis-iis/farmer-health): IIS Django/Python project.
- [devTools](https://github.com/memphis-iis/devTools): IIS developer toolkit (iisaeTools, praat_automation, pythonCSVCombiner, and selenium).
- [iis-public-library](https://github.com/memphis-iis/iis-public-library): IIS public script library.
